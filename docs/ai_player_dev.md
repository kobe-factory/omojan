# AIがゲームに参加する機能追加
ユーザーとの対話できまったことは必ずドキュメントに残す
わからないことは必ずユーザーに聞く。予測で進めない。
すぐ実装を始めない。ユーザーからの指示を待つ。

## AIがプレイヤーとして１名参加するゲーム設定追加
- 大会発行時にAIプレイヤーを参加させるオプションを追加
- ６人目のユーザーとしてAIプレイヤーが参加する
- AIユーザーは、「リナちゃん」「デスク・大河内」等が選べる（## AIプレイヤーについてを参照）
- 札作成、お題に対する札の選択、位置設定、前口上のテキスト、位置設定を通常ユーザーと同様に行う。
- AIユーザーはおもじゃんのゲーム特性を理解し、札と前口上を使ってめちゃくちゃ面白い作品を作成する。
- 札作成時の文字数は1〜20文字で作成。
- 前口上のテキスト生成は1〜30文字で作成。
- 個人結果の部分にはAIプレイヤーの表記や分析はなしでOK
- 過去結果（大会結果には）AIプレイヤーの作品や結果は残す

## AIが札作成をするゲーム設定追加
- 大会発行時にAIが札を全て作成するモードを選択できるようにする
- 作成する札の枚数は、発行時の大会設定に準拠する
- 札作成時の文字数は1〜20文字で作成。
- 文字数が少ないもの、単語だけ、文章、前後に文字をくっつけると文章になりそうなものを生成する
- 札の文字数はバラエティ豊かなパターンで生成する
- 下ネタ枠は、直接的な表現が難しい場合、間接的な表現でOK

## AIエキシビションモード
- それぞれ５名のAIが戦うモード
- 対戦モードは通常モードとシークレットモードのランダムで行う（なりすましはなし）
- 決戦モードは連打モード
- 最初のユーザー選択はユーザーが行う
- 全画面、通常ユーザーと同じとするが、ユーザーは操作できないようにする。入力や選択項目がdisabledの状態。そのユーザーのAIが入力済みの状態とする。編集はできない。投稿や投票のボタンだけユーザーが行う。そうすることで各ユーザーがそれぞれのステップで自分のAIがどういったものを作成・選択したかがわかるしくみ。ユーザーは内容を見てから次のステップに進めるようにする
- 決戦モードだけは、通常ユーザーがやる仕様とします。
- エキシビションモードは、通常ユーザーの過去結果の記録には含まない。エキシビションモードだけの過去結果を見るタブを設けたい。

## AIモデル設定（src/lib/ai-config.ts）

AIコメント生成・AIプレイヤーのモデルは `src/lib/ai-config.ts` で管理しており、環境変数で切り替え可能。

### デフォルト値（環境変数未設定時）

| 用途 | デフォルトモデル | コスト感 |
|---|---|---|
| AIコメント生成（リナちゃん・大河内） | `claude-haiku-4-5-20251001` | ~$0.05/大会 |
| AIプレイヤー（未実装） | `claude-sonnet-4-6` | ~$0.20〜0.35/大会 |

**環境変数を設定しなければデフォルト値が自動的に使われる。Vercelの環境変数に追加しなくても動作する。**

### 切り替え方法

**ローカル（.env.local）：**
```
AI_MODEL_COMMENTS=claude-sonnet-4-6
AI_MODEL_PLAYER=claude-haiku-4-5-20251001
```

**本番（Vercel）：**
Vercel ダッシュボード → Settings → Environment Variables に追加。
再デプロイ不要で反映される。
未設定のままにしておけばデフォルト値が使われる。

### 利用可能なモデル

| モデルID | 特徴 | コスト |
|---|---|---|
| `claude-haiku-4-5-20251001` | 高速・低コスト | 最安 |
| `claude-sonnet-4-6` | 高品質・複雑な指示に強い | Haikuの約3〜4倍 |

### キャラ設計方針

- **全キャラ実装する**
- **面白さ最優先**：平均的なキャラではなく、データを元に面白いキャラを目指す
- **個人AIキャラ（こんべ(AI)等）**：その人の作品・札データを読み込んでキャラ付け。「この人ならこんな回答をしそう」という予測から面白い作品を作ることに注力する
- **Fuw-Fuw**：5名全員の個性から面白い作品と札を作るカオスキャラ。5名の平均ではなく、全員の個性を増幅させたもの

### データ設計方針

- **Vercelはファイル書き込み不可**のため、キャラクタープロンプトデータはDBに保存する
- 提案テーブル：`ai_player_characters`（キャラ設定テキスト、各ユーザーの過去データ等を格納）
- 個人AIキャラのデータ（作品・札の傾向）はDBから取得し、カラムとして保存しておく
- データ更新のタイミングは大会発行時 or 手動更新とする（頻繁な更新は不要）

### AIのアクションタイミング

- ゲームの各フェーズでAIが必要なアクションをポーリング時にFire-and-forgetで実行する
- 通常ユーザーと同じDBテーブルに書き込む（submissions, votes等）
- 連打ゲームへのAI参加については未決（後述の未決事項参照）

### コスト試算

- 既存のリナちゃん＆大河内コメント生成の実測値：**約$0.05/大会**（1大会5回戦分）
- AIプレイヤーが1大会に参加する場合の追加コスト試算（Claude Haiku 4.5ベース）：

| 処理 | 呼び出し回数 | 推定コスト |
|---|---|---|
| 札作成（20枚） | 1回 | ~$0.01 |
| 各回戦：作品作成（手札選択＋位置＋前口上） | 5回 | ~$0.01 |
| 合計/大会 | 6回 | ~$0.02 |

- **1大会あたりAIプレイヤー追加コスト：約$0.02〜$0.05程度**
- $5チャージで約100〜250大会分の余裕あり → **実現可能**
